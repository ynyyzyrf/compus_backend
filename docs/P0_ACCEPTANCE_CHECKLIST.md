# P0 驗收清單

> 用途：在微信開發者工具或真機中逐項驗收 P0 閉環。每一項建議保存截圖或錄屏，發現問題後記錄頁面、操作步驟、報錯文字。

## 1. 基礎啟動

- [ ] 微信開發者工具可正常打開項目，無紅色編譯錯誤。
- [ ] 首頁正常顯示「校友商會」標題、快捷入口、活動卡片、公告卡片。
- [ ] 底部 tab 可在首頁、活動、消息/公告、我的之間切換。
- [ ] 控制台無 `ReferenceError`、`ENOENT`、資源超限等阻塞錯誤。

## 2. 登錄與身份

- [ ] dev mock 登錄可正常獲取當前用戶。
- [ ] 普通用戶與超級管理員身份切換後，頁面權限符合預期。
- [ ] 首次資料引導可進入，也可稍後填寫。
- [ ] 我的頁能展示用戶名稱、學院/系/班級、管理入口。

## 3. 通訊錄與名片

- [ ] 通訊錄列表可正常加載。
- [ ] 搜索姓名、專業、公司等關鍵詞可返回結果。
- [ ] 學院/系/班級篩選可正常切換。
- [ ] 點擊校友卡片可進入名片詳情頁。
- [ ] 名片詳情頁展示聯絡方式、公司、職位、專業、資源、簡介等字段。
- [ ] 權限限制正常：無權查看的跨範圍會員不可見或返回無權提示。

## 4. 新聞公告

- [ ] 公告列表可打開並正常展示。
- [ ] 類型 tab 可切換。
- [ ] 點擊公告可進入詳情頁。
- [ ] 發布範圍生效：不同身份只能看到自己有權查看的公告。
- [ ] 超級管理員可進入公告管理、新建、編輯、刪除公告。

## 5. 活動閉環

- [ ] 活動中心 tab 不重疊，活動卡片顯示正常。
- [ ] 活動詳情頁可打開，顯示時間、地點、報名人數、介紹等信息。
- [ ] 用戶可報名活動。
- [ ] 用戶可在報名截止前取消報名。
- [ ] 重複報名、過期取消、未報名簽到等異常場景有正確提示。
- [ ] 超級管理員可創建/編輯活動。
- [ ] 超級管理員可查看活動名單與簽到率。
- [ ] 掃碼簽到流程可跑通，重複簽到有正確提示。

## 6. 管理中心

- [ ] 超級管理員可看到管理中心入口，普通用戶不可見。
- [ ] Dashboard 統計卡片顯示正常。
- [ ] 人員管理可搜索、編輯、啟用/停用成員。
- [ ] 組織管理可展示樹、新建、改名、刪除節點。
- [ ] 權限管理開關可保存並影響通訊錄可見範圍。
- [ ] 活動管理、公告管理可從管理中心進入。
- [ ] 接龍、相冊審核、AI 數據助手可從管理中心進入；普通用戶不可進入管理頁。

## 7. 多語言

- [ ] 我的頁語言切換可在簡體中文與繁體中文之間切換。
- [ ] 首頁、通訊錄、活動、公告、我的頁主文案跟隨語言切換。
- [ ] 深層頁面無明顯簡繁混雜。
- [ ] toast、彈窗、空狀態、錯誤提示無明顯簡繁混雜。

## 8. 包體與資源

- [ ] 上傳代碼不再出現 `source size exceed max limit 2MB`。
- [ ] 首屏圖片正常顯示，無丟圖、變形、黑塊。
- [ ] `miniprogram/` 下不存在單文件超 2MB 的源碼/資源文件。

## 8A. P1 新增能力

- [ ] 活動詳情可進入活動相冊。
- [ ] 普通用戶可提交照片，提交後進入待審核，不立即出現在公開相冊。
- [ ] 超級管理員可在相冊審核頁看到待審核照片，並通過/拒絕。
- [ ] 通過後照片出現在活動相冊；拒絕後不出現在公開相冊。
- [ ] 我的頁可進入「我的上傳」，看到自己提交的照片與審核狀態。
- [ ] 活動詳情可進入分享海報頁，海報包含活動名稱、時間、地點、組織名稱、活動圖與小程序碼占位。
- [ ] 分享海報可保存到系統相冊。
- [ ] 管理中心 AI 數據助手僅超管可用；未配置 API key 時提示後端配置錯誤，不影響其他功能。
- [ ] 配置 API key/model 後，AI 助手可基於活動、報名、簽到、組織、成員、接龍、內容等受控工具回答。

## 9. 後端與接口

- [ ] 後端服務啟動正常，健康檢查可訪問。
- [ ] `pytest` 全量通過。
- [ ] 小程序 dev 環境 Base URL 指向正確後端。
- [ ] 401/403/404/409 等錯誤提示符合預期。

## 10. P0 驗收結論

- [ ] 所有 P0 主流程可在微信開發者工具跑通。
- [ ] 至少完成一次真機驗收。
