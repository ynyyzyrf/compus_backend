## 手工维护工具

`backend/scripts/normalize_academic_data.py` 默认为只读预览；不会在部署时自动执行。仅接受已核对的旧组织结构；遇到未知组织或真实数据拒绝猜测。

- 连接串从 `CAMPUS_MAINTENANCE_DATABASE_URL` 环境变量读取，不写入代码或报告。
- 简体转换采用维护环境中的 `opencc-python-reimplemented==0.1.7`，不增加后端运行时依赖。
- 预览：`python scripts/normalize_academic_data.py`。
- 应用：额外传入 `--apply --backup-dir <仓库外的备份目录>`。
- 写入前保存全部公共表数据并校验备份字节，事务内完成更新和校验，失败回滚。
- 只转换明确列出的展示字段和 JSON 值，保留 JSON 键、账号标识、联系方式、链接及 HTML 属性。
- 本次备份及回执位于当前 Windows 用户的 `AppData/Local/CampusPlatform/backups/`，包含个人数据，不应上传 GitHub。

无需重新上传小程序即可读取线上数据库更新；模拟器使用的是独立本地数据库，本次未覆盖其测试数据。
